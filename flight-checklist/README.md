# צ׳קליסט הכנה לטיסה ✈️

אפליקציית PWA בעברית (RTL) להכנות לטיסה, מהזמנת הכרטיס ועד הנחיתה.

## תכונות
- 10 שלבים ורשימת משימות מלאה.
- סימון התקדמות באחוזים.
- שמירה אוטומטית במכשיר.
- שיתוף/העתקת סיכום ההתקדמות.
- אפשרות התקנה במסך הבית ותמיכה בסיסית בעבודה ללא רשת לאחר טעינה ראשונה.

## פרסום
האתר מיועד ל-GitHub Pages כתיקייה סטטית.
